# UGC.KZ — креатор для вашего бренда

**Живая ссылка:** https://brilliant-duckanoo-e7e54f.netlify.app

UGC.KZ — маркетплейс, который соединяет бренды Казахстана с UGC-креаторами (авторами коротких видео и фото для рекламы). Бренд находит креатора по городу, категории и бюджету, смотрит портфолио и отзывы и пишет ему прямо на сайте. Креатор создаёт профиль, загружает видео и получает заказы.

**Проблема.** Малому и среднему бизнесу нужен рекламный контент для Instagram и TikTok, но агентства дорогие, а искать креаторов по чатам и директу долго и рискованно.
**Решение.** Каталог проверенных креаторов из 18 городов с ценами, рейтингом и отзывами брендов, плюс заявка в один клик.

## Возможности

- Регистрация и вход для двух ролей: **бренд** и **креатор**.
- Каталог креаторов с фильтрами (город, категория, тип контента, цена) и сортировкой.
- Профиль креатора: портфолио (загрузка видео до 50 МБ), цены, описание.
- Сообщения: бренд пишет креатору, креатор видит входящие и отвечает.
- Отзывы и рейтинг: бренд ставит 1–5 звёзд, рейтинг считается на сервере.
- Статистика платформы на главной.
- 3 языка: қазақша / русский / English.

## Архитектура

```
Браузер (index.html)
   │  fetch /api/*
   ▼
Бэкенд: Netlify Functions (netlify/functions/api.mjs)
   │  REST + JWT пользователя
   ▼
БД: Supabase (PostgreSQL + Auth + Storage)
   — таблицы creators, brands, messages, reviews
   — RLS-правила: писать и менять может только владелец
   — триггер: профиль создаётся автоматически при регистрации
```

| Часть | Технологии |
|---|---|
| Фронтенд | HTML, CSS, JavaScript (без сборки), SPA с роутером на hash |
| Бэкенд | Node.js, Netlify Functions |
| База данных | Supabase (PostgreSQL), Auth, Storage |
| Хостинг | Netlify (автодеплой из ветки `main`) |

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/health` | проверка, что сервер жив |
| GET | `/api/data` | креаторы (с рейтингом, посчитанным на сервере), бренды, отзывы |
| GET | `/api/creators?q=&city=&cat=&type=&max=&sort=` | поиск и фильтрация креаторов; `sort` = `r`, `p_asc`, `p_desc`, `new` |
| GET | `/api/brands` | список брендов |
| GET | `/api/stats` | статистика: количество креаторов, брендов, отзывов, городов, средняя цена и рейтинг |
| GET | `/api/cities` | список городов |
| POST | `/api/messages` | отправить сообщение креатору (нужен токен; имя и email берутся на сервере из токена) |
| POST | `/api/reviews` | оставить отзыв 1–5 (нужен токен; только бренд, один раз, не себе) |

Пример: https://brilliant-duckanoo-e7e54f.netlify.app/api/stats

## Структура репозитория

```
index.html                 — фронтенд (стили, 3 языка, страницы)
netlify/functions/api.mjs  — бэкенд (API)
netlify.toml               — настройки деплоя
supabase-setup.sql         — схема БД, RLS-правила, триггер, хранилище видео
```

## Запуск и деплой

1. **БД.** Supabase → SQL Editor → выполнить `supabase-setup.sql`.
2. **Ключи.** В `index.html` указать `SUPABASE_URL` и `anon public` ключ. Для бэкенда можно задать переменные окружения `SUPABASE_URL` и `SUPABASE_ANON_KEY` в Netlify. `service_role` ключ никуда не вставлять.
3. **Деплой.** Netlify → Import from GitHub → этот репозиторий. Настройки берутся из `netlify.toml`, после каждого пуша в `main` сайт обновляется сам.
4. **Локально:** `npx netlify-cli dev`, сайт откроется на http://localhost:8888 вместе с API.
