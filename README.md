# UGC.KZ — a creator for your brand

Бренд пен креаторларды біріктіретін сайт (18 қала). Таза HTML + CSS + JavaScript, сборка керек емес. Деректер, аккаунттар және видеолар **Supabase**-те сақталады.

## Файлдар

```
index.html            — бүкіл сайт (стиль, 3 тіл, беттер, роутер) бір файлда
supabase-setup.sql    — Supabase-ке бір рет іске қосатын SQL (кестелер, қауіпсіздік, видео бакеті)
```

## Supabase баптау (бір рет)

1. [supabase.com](https://supabase.com) → жаңа жоба жасаңыз.
2. **SQL Editor** → `supabase-setup.sql` мазмұнын қойып, **Run** басыңыз.
   Бұл тіркелген бойда креатор/бренд профилін автоматты жасайтын триггерді қосады
   және бұрын тіркеліп, профилі сақталмай қалғандарды қалпына келтіреді.
3. **Project Settings → API**: `Project URL` мен `anon public` кілтін `index.html` жоғарындағы
   `SUPABASE_URL` және `SUPABASE_KEY` жолдарына қойыңыз.
   (anon кілт ашық болуы қалыпты — деректі RLS ережелері қорғайды. `service_role` кілтін ЕШҚАШАН қоймаңыз.)
4. **Authentication → Providers → Email**: «Confirm email» өшірулі болса — тіркелген бойда кіреді;
   қосулы болса — пайдаланушы поштадағы сілтемені басуы керек.
5. **Authentication → URL Configuration**: Site URL ретінде сайт мекенжайын жазыңыз.

## Қалай жұмыс істейді

- Тіркелу: бренд немесе креатор Supabase Auth арқылы аккаунт ашады. Креатор профилі (`creators`) мен бренд (`brands`) иесінің `owner_id`-імен сақталады.
- Каталог пен Brands беті барлық адамға ортақ деректі көрсетеді.
- Профильді, бейнені өзгерту/өшіру — тек иесіне (RLS).
- Байланыс: бренд «Связаться» арқылы жазған хабар базаға түседі; креатор оны «Хабарламалар» бетінде көреді және брендтің email-іне жауап бере алады.
- Пікірлер: бренд креаторға 1–5 жұлдыз және пікір қалдырады (әр креаторға бір рет, өз профиліне жазуға болмайды). Креатор рейтингі пікірлерден автоматты есептеледі.
- Креатор өз профилін өңдей алады (аты, қала, санат, баға, өзі туралы).
- Видео: файл (≤ 50 МБ) Supabase Storage-тегі `videos` бакетіне түседі, не болмаса сілтеме қосылады.

## Жергілікті іске қосу

`index.html` файлын браузерде ашу жеткілікті. Немесе: `python3 -m http.server 8000`

## GitHub Pages

1. Репозиторий жасап, `index.html` (және `supabase-setup.sql`) салыңыз.
2. **Settings → Pages → Deploy from a branch → main / (root)**.
3. Сайт `https://<аты>.github.io/<репо>/` мекенжайында ашылады.

## Тілдер

Хедердегі таңдау арқылы тіл ауыстырылады (kk / ru / en). Жаңа мәтін қосу үшін `index.html` ішіндегі үш сөздікке (`D.ru`, `D.kk`, `D.en`) де кілт қосыңыз және кодта `t("кілт")` деп жазыңыз.
